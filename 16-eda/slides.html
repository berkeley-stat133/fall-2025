Quarto

Quarto

Quarto is an open-source scientific publishing system that you can run at the command line.

  1. Source document is .qmd and output document can be a pdf, a webpage, slides, a dashboard, etc.

  2. The source document can hold text, images, videos, and code.

  3. Rendering the source document runs all the code and puts the data products into the output document.

    $ quarto render mydoc.qmd

  4. Microsoft Word + Microsoft Excel + a lot more.

Positron

Positron

Positron is an Integrated Development Environment (IDE) that makes it easy to pull together many different tools to do Data Science.

  1. Shell, R, Editor, Viewer, git, and Quarto all in one place
  2. Successor to RStudio
  3. R, Python, and Julia are equal citizens

Labels

The labels on the plot can refer to many different places where text is added to describe what is plotted.

  • title
  • subtitle
  • x-axis
  • y-axis
  • legends

In ggplot2, these are arguments to a labs() layer.

  • title
  • subtitle
  • color
  • fill
  • size
  • shape

Labels

ev |>
  ggplot(aes(x = State, y = Count)) +
  geom_col() +
  theme(axis.text.x = element_text(angle = 270, 
                                   hjust = 0, 
                                   vjust = 0.5)) +
  labs(title = "Electric Vehicle Registrations by State",
       x = "",
       y = "Registration Count")

Themes

Themes describe a set of visual design choices made for the plot on things like the background, the gridlines, the axes, the tick marks, and the fonts.

Some ggplot2 themes (each one can be added as layer)

  • theme_gray(): the default
  • theme_bw()
  • theme_minimal()
