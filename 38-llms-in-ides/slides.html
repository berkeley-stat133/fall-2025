Contextual Chat

Recall Paris…

library(ellmer)
claude <- chat_claude()
claude$chat("The capital of France is?")
Using model = "claude-sonnet-4-5-20250929".
The capital of France is Paris.
claude$chat("what is the biggest city?")
Paris is also the biggest city in France, with a population of over 2 million people within the city proper and
over 12 million in the greater metropolitan area (Île-de-France region).

The previous query was the context.

claude2 <- chat_claude()
claude2$chat("what is the biggest city?")
# The Biggest City

The answer depends on how you measure "biggest":

## By Population
**Tokyo, Japan** is the largest, with about **37-38 million people** in its metropolitan area.

## By Land Area
**New York City, USA** or **Brisbane, Australia** (depending on how boundaries are defined) are among the
largest by area, though some Chinese cities like **Chongqing** also claim large administrative areas.

## By Urban Density
Cities like **Manila, Philippines** or **Dhaka, Bangladesh** have extremely high population densities.

**Most commonly, "biggest city" refers to population, making Tokyo the answer.**

Context in LLMs

  • Context: additional info provided to LLM to help generate better responses.
  • Examples of context:
    • Code
    • Data
    • Documentation
SYSTEM: You are a helpful coding assistant.
CONTEXT:
File: R/my_add.R
--------------------------------
my_add <- function(a, b){ return a+b }

USER: can you add subtract?

Agentic AI

What is Agentic AI in an IDE?

A coding assistant that can autonomously perform multi-step actions toward a goal — such as editing files, running code, searching the project, and verifying outcomes — using feedback from the environment to decide what to do next.

Positron Assistant: Agent Mode

  • Demo
  • Can create, edit, run files
  • Proposes changes to files that you can approve or reject
  • Caution: there are serious risks with allowing an AI to edit your file system!
