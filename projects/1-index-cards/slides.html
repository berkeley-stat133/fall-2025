Using the Shell Locally

    • “zshell” (aka zsh) - UNIX based. Very similar to bash (Base UNIX Shell) with some added functionality.
    • To access, use the Mac’s “Termial” application.
  2. Windows:
    • Will need to install “Git” if you don’t have it already.
      • https://git-scm.com/downloads
    • This will give you access to the “Git Bash” application, which will let you use UNIX Shell on your Windows system.

Brief Review of Lecture

New Shell Commands

mkdir

Creates a new directory.

cp

Copy file (arg1) to destination (arg2).

Example: cp ~/Downloads/hw1.pdf ~/Documents/econ100b/hw/

mv

Move file (first argument) to destination directory (second argument).

Example: mv ~/Downloads/hw1.pdf ~/.Trash

They have only heard mv in lecture briefly, so teach them the functionality.

Brief Review of Lecture (cont.)

R Equivallent of Shell Commands:

  • getwd(): like pwd in Shell.

  • setwd(): like cd in Shell.

  • list.files(): like ls in Shell.

  • readLines(): like cat in Shell.

Brief Review of Lecture (cont..)

  • a:b: Creates vector of numbers from a to b by 1.
  • seq: Creates vector of numbers from "from" argument, to "to" argument, by steps defined in the "by" argument.
  • rep: Repeats vector provided "x" a number of times defined by "times" argument.

Vectorization

  • Operations on a single object also works on vectors.
vec <- c(72, 52, 10)

vec / 2
[1] 36 26  5


vec * 3
[1] 216 156  30


vec - 6
[1] 66 46  4

Recycling

  • Operations on two vectors of unequal length.
vec1 <- 1:10
vec2 <- c(1, 2)

vec1 * vec2
 [1]  1  4  3  8  5 12  7 16  9 20


vec3 <- c(1, 2, 3)

vec1 + vec3
 [1]  2  4  6  5  7  9  8 10 12 11
