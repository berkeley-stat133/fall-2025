if-then

“if then” statement: executes a block of code if a condition is met.

x <- rnorm(1)

if (x > 0) {
  print("x is positive :)")
}

if-else

“if else” statement: executes one block of code if a condition is met and a different block of code if it is not met.

x <- rnorm(1)

if (x > 0) {
  print("x is positive :)")
} else {
  print("x is negative :(")
}

Similarly, run it multiple times and annotate code with different colors: if-then syntax, logical condition, and what to do.

Nested ifs

x <- rnorm(1)

if (x > 0) {
  print("x is positive :)")
} else if (x < 0) {
  print("x is negative :(")
} else {
  print("x is zero :|")
}
